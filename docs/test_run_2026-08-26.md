# Recorded migration test: 2026-08-26

## Scope

- dbt Core: 1.12.3
- Adapter: dbt-dlc 1.1.1
- Target namespace: `DataLakeCatalog.athena_migration`
- Project: 15 models, 31 data tests, 6 seeds
- Athena execution: none
- Kaggle data: none

## 1. Offline parse and compile

Input: all project SQL, YAML, tests, profiles, and seed declarations.

Commands:

```bash
dbt parse --target parse --no-partial-parse
dbt compile --target parse --no-partial-parse --no-introspect --no-populate-cache
python scripts/inspect_manifest.py target/manifest.json
```

Produced compiled SQL, `manifest.json`, and `namespace_compile.csv`. All 21
model/seed resources had catalog, schema, and identifier. This checked dbt
parsing and relation rendering only; it did not execute SQL.

`dbt seed --full-refresh` created all six relations. Result: 6 passed.

## 3. Unchanged Jaffle baseline

Produced three staging views (`stg_customers`, `stg_orders`, `stg_payments`) and
two final tables (`customers`, `orders`). The models exercised refs, views,
tables, joins, aggregations, and Jinja-generated payment columns.

Twenty tests checked identifier uniqueness/non-nullness, accepted order status,
accepted payment method, order-to-customer relationships, and non-null final
amount fields. Result: 5 models and 20 tests passed.

## 4. Three-level namespace

`namespace_probe` selected from `ref('raw_orders')`. Its live view creation
passed, and manifest inspection rendered every model/seed relation as
`catalog.schema.identifier`. The probe did not separately assert that its count
was 99.

## 5. Original Athena expressions on DLC

| Expression | DLC observation |
|---|---|
| `from_iso8601_timestamp(...)` | unresolved routine |
| `try(date_parse(...))` | `try` unresolved |
| `date_parse(...)` | unresolved routine |

These four cases were observations, not required passes. They established which
expressions need conversion without provisioning Athena.

## 6. Converted expressions

The converted models used `to_timestamp`, `to_date(..., 'yyyy-MM-dd')`, and
`get_json_object`. They produced three transformation views and the joined
`dlc_pattern_results` view.

Six tests checked unique/non-null IDs, non-null parsed timestamps and dates,
non-null channels, and exact channels (`web`, `mobile`, `store`) by ID. Result:
4 models and 6 tests passed. Date/timestamp exact equality and malformed input
semantics were not tested.

## 7. Iceberg MERGE

Batch 1 full-refreshed two rows:

```csv
order_id,customer_id,order_date,status,amount_cents
1,10,2024-01-01,placed,1000
2,20,2024-01-02,placed,2000
```

Batch 2 updated order 1 and inserted order 3. The final table was reconciled in
both directions with `EXCEPT` against this expected result:

```csv
order_id,customer_id,order_date,status,amount_cents
1,10,2024-01-01,shipped,1200
2,20,2024-01-02,placed,2000
3,30,2024-01-03,placed,3000
```

Both model executions passed. Exact reconciliation, unique order ID, and three
non-null tests also passed.

## Result

The live script executed 50 successful dbt nodes and recorded four intentionally
observed failures for unconverted Athena functions. All required Jaffle,
namespace, converted SQL, and Iceberg MERGE cases passed.

Raw logs and generated dbt artifacts remain local and are ignored by Git.
